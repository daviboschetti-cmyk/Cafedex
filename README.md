# ☕ Cafedex
## 📖 Sobre o projeto

Neste projeto foi criada uma página web para uma cafeteria utilizando HTML e CSS.

A página possui:
- Cabeçalho
- Página principal
- Cardápio
- Sobre nós
- Contato
- Rodapé

## 🧠 O que eu aprendi

Aprendi a utilizar o **Flexbox** para organizar os elementos da página.

### 📌 Principais códigos do Flexbox

- `display: flex` → ativa o Flexbox.
- `flex-direction` → define a direção dos elementos.
- `justify-content` → alinha os elementos no eixo principal.
- `align-items` → alinha os elementos no eixo contrário.
- `align-content` → organiza as linhas de elementos.
- `flex-wrap` → permite que os elementos quebrem para outra linha.
- `gap` → cria espaço entre os elementos.
- `flex-grow` → permite que o elemento cresça.
- `flex-shrink` → permite que o elemento diminua.
- `flex-basis` → define o tamanho inicial do elemento.
- `order` → muda a ordem dos elementos.

## 🎯 Conclusão

Essa atividade me ajudou a entender melhor como o **Flexbox funciona** e como ele pode ser usado para criar páginas mais organizadas, bonitas e responsivas.
